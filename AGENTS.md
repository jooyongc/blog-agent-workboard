# Blog Agent Workboard

The active product is the Cloudflare Pages Workboard under `workboard/` and the separate `scheduler/` Worker. The user's current operating sites are Korea Buy List (Blogger, independently written English and Japanese), Korea by Local, and Korea Decode. ASTY and Naver are disconnected from the active catalog and scheduler.

The older ASTY CLI and its historical instructions are retained only for reference in `docs/LEGACY-AGENTS.md`. Do not copy ASTY voice, affiliate text, translation settings, pipeline schedules, or URLs into the three active sites. Current user authorization supersedes older advice to keep Aside as Blogger scheduler: the Aside routine was paused for the Cloudflare transition.

The site-specific publishing strategy is stored in D1 `workspace_records` and editable in Workboard. Restore the SEO/AEO/GEO rules from `workboard/skills/seo-aeo-geo/` and respect verified source evidence, visible FAQ/JSON-LD parity, actual dates, raw HTML checks, and two-week measurements. Never assert that rankings or citations improved without measured data.

Before a production change: build and test `workboard`, apply D1 migrations, deploy Pages and the scheduler Worker, and verify the production route. Keep service credentials server-side. The latest user direction is approval-only operation through separate agents and automatic private draft delivery. Do not auto-approve generated topics. The harness must use Cloudflare Queues, persist role checkpoints, pass research and quality checks, and retain duplicate-prevention receipts. Public publishing remains a separate explicitly configured action. Media must include at least two licensed/free commercial-use photos; retain credits and source/license metadata. Adobe Firefly web credentials do not grant API access, and the existing organization currently lacks Firefly API entitlement.

The active provider is Gemini: the senior supervisor and correction editor use Gemini 3.1 Pro, and research, first drafting and preliminary verification use Gemini 3.8 Flash. Anthropic Sonnet 5.5/Haiku 4.5 remain available when AI_PROVIDER is explicitly set to anthropic. Gemini keys stay only in server-side secrets; the two user-designated Utop projects share the same key. Failed verification escalates automatically to the supervisor. Persist its concise decisions, assignments and review rounds (maximum three) and an approval fingerprint of the exact DraftInput; publishing requires that fingerprint to match. Never override factual or structural checks merely to drain the queue. Source/format repairs preserve licensed media and keep photos out of Quick Answer. Execution belongs to Cloudflare Queues and continues without an open browser tab. Site budgets are independent; review and correction costs count toward the same article budget.
